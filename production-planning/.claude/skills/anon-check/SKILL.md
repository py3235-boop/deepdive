# 익명화 전수 검사

대회 산출물 어디에도 실제 고객사명·회사명·공정명·사내 식별자가 없어야 한다. 사람이 눈으로 찾지 말고 스크립트로 전수 검사한다.

## 실행
```bash
python .claude/skills/anon-check/anon_check.py
```
- 기본 대상: `split/`, `data/`, `scripts/`, `docs/`, `.claude/agents/`, 루트의 파일
- 특정 파일/폴더만: `python .claude/skills/anon-check/anon_check.py split/Code.gs 발표자료.md`
- 종료 코드 0 = 통과, 2 = 위반 있음(stderr에 파일·줄·내용)

## 검사 항목
| 구분 | 내용 |
|---|---|
| 금지어 | 고객사 실명, 실제 공정명, 더미가 미러하는 실제 품목코드, 회사 도메인·사내 시스템명 — 스크립트 상단 `TERMS` |
| 식별자 | Drive 폴더 URL, 스프레드시트 URL, GAS 스크립트 URL — 스크립트 상단 `PATTERNS` |
| 비밀값 | Google Chat 웹훅 URL, 텔레그램 봇 토큰, 회사 이메일 |
| xlsx 셀 | `기준정보.xlsx` 등 스프레드시트 전 시트의 셀 값도 같은 기준으로 검사 — openpyxl 필요(없으면 경고 후 생략) |

## 절차
1. 실행 → 위반이 있으면 **줄 단위로 전부 고친다** (고객사A/B/C, 집합XX호기, 토큰은 스크립트 속성으로, URL은 CFG 플레이스홀더로).
2. 다시 실행해 `✅ 통과`를 확인한다.
3. 결과 시트·알림 메시지 문구도 코드에 문자열로 있으므로 함께 잡힌다. 시트에 이미 써진 값은 별도로 눈으로 확인한다(#10).

## 자동 실행
`.claude/settings.json`의 PostToolUse 훅이 Edit/Write마다 저장된 파일 1개를 같은 스크립트(`--hook`)로 검사한다. 훅이 위반을 알리면 다음 작업으로 넘어가지 말고 즉시 고친다.

## 금지어 추가
스크립트 상단 `TERMS` 리스트에 문자열을 추가한다. 실명·회사명은 이 파일과 스크립트 외에는 어디에도 적지 않는다.
