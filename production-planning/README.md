# production-planning

집합공정 **생산계획 자동화** — Google Apps Script (V8).

출고계획 스프레드시트를 읽어 출하계획으로 변환하고, 설비 여력·규격교체·납기를 따져 호기별 생산계획을 자동으로 세운 뒤 담당자에게 Google Chat으로 알린다.

## 담당 범위

전체 4단계 중 **②③④**를 맡는다. (① 발주서 판독은 `balju-automation`)

| 단계 | 내용 |
| --- | --- |
| ② 출고계획 → 출하계획 변환 | 파일명 패턴으로 출고계획 파일을 찾아 가로 날짜형 표를 세로 4열로 펴고, `(품목코드, 고객사, 출하일)` 키로 upsert |
| ③ 생산계획 자동 수립 | 기초재고 차감 → 부족분만 보빈 단위로 올림 배정 → 규격교체 회피·납기·전담 호기·Payoff 제약을 순서대로 적용해 호기 선택 → 시간 시뮬레이션 |
| ④ 알림 | Google Chat 카드 발송 (텔레그램·메일 폴백) |

## 폴더 구성

```
split/            Apps Script 소스 (기준정보 스프레드시트에 바인딩)
  Code.gs         진입점 · 설정(CFG/SHEET) · 데이터 로드 · 트리거 · 메뉴
  Planner.gs      호기 배정 → 작업목록 배열 반환
  Scheduler.gs    근무시간 기반 시간 시뮬레이션
  Publisher.gs    결과 시트 렌더링 (모든 뷰)
  Utils.gs        날짜·변환·시트/Drive 헬퍼 · 알림
기준정보.xlsx      샘플 기준정보 11탭 (익명화된 더미데이터)
실적/             샘플 생산실적·출하실적 (실적 시스템 내보내기 양식)
CLAUDE.md         프로젝트 규칙 · 계획 로직 12개 규칙 · 탭 명세
작업일지.txt       작업 기록
```

## 입출력

- **입력** — 기준정보 스프레드시트 1개(탭 = 데이터 종류) + 출하계획 스프레드시트 1개(변환 산출물, 판독 파트 인터페이스)
- **출력** — 생산계획 스프레드시트 1개(고정 링크, 탭 18개) + 호기별 작업지시서 파일 10개(현장 배포용, 링크 불변)
- 파일 ID는 비어 있으면 스크립트가 처음 한 번만 만들어 스크립트 속성에 저장한다. 공유된 링크가 바뀌지 않는다.

## 실행

기준정보 스프레드시트의 **[▶ 생산계획]** 메뉴에서 실행한다.

- `지금 재계획` — 전체 파이프라인 1회
- `최신 계획 열기` · `호기별 작업지시서 링크` · `이전 계획 보기`
- `설정 → 트리거 설치` — 기준정보 변경 감지(onChange) + 1분 주기 파일 감지

단계별 단독 테스트 함수도 있다: `testLoadOnly` · `testConvertOnly` · `testPlanOnly` · `testActualsOnly` · `testPublishOnly` · `testNotifyOnly`.

## 계획 로직 요약

| 상수 | 값 |
| --- | --- |
| 일과 시작 | 08:00 (근무일 24시간 연속, 주말·휴무 제외) |
| 계획 첫날 가동준비 | 3h |
| 규격교체 | 1.5h |
| 연속 배정 한도 | 72h (초과 시 보빈 단위로 분할) |

호기 선택 순서: 절대차단·Payoff·기종 → **규격교체 회피** → 재고 보충 → **납기 우선** → 전담 호기 예약 → 우선설비 → 동일규격 → 최속.

생산량은 항상 보빈(CAPA 중량) 배수로 올린다 — 자투리는 현장에 내릴 수 없기 때문이다.

## 데이터 원칙

- **단일 진실 원천**: 계획 결과는 `[작업목록]` 탭으로 먼저 쓰고 다시 읽는다. 일 단위 뷰는 파생 테이블 `[일별생산]`만 읽는다. 시뮬레이션 객체를 뷰가 직접 참조하지 않는다.
- 시트 I/O는 `getValues`/`setValues` 배치만 쓴다 (셀 단위 루프 금지 — 6분 실행 제한).
- 스프레드시트·폴더 ID, 탭 이름, 품목·설비·고객사 목록은 `CFG`/`SHEET` 한 곳에만 둔다.
- 웹훅 URL·토큰은 코드에 두지 않는다 (스크립트 속성).
- 저장소의 데이터는 전부 **익명화된 더미데이터**다 — 고객사는 `고객사A`~`고객사C`, 설비는 `집합01호기`~`집합10호기`. `.claude/skills/anon-check`가 전수 검사한다.

## 검증 현황

오프라인 하네스(가짜 Sheets/Drive)로 46건 통과. 출하계획 변환 122행·99,218kg 대조 완료, 재고 항등식 8품목 일치, 호기별 작업지시서 10개 링크 유지 확인.
